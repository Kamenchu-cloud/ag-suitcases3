# AG Suitcases Collection — 2026 Catalogue Mapping

Canonical mapping from the WhatsApp catalogue archive to the website product records.

## Rules used

- One website product record represents one catalogue group/style family.
- `Primary image` is the first image used on product cards and as the initial product-detail image.
- `Additional images` are representative supporting views selected from the same catalogue group.
- Colour names are only included where they are visible/identifiable in the catalogue material; otherwise the record uses `Multiple`.
- Group 11 is retained as a catalogue-reference product because its source images are WhatsApp/catalogue reference screenshots rather than clean product photography.
- Prices on the website remain explicitly marked as **indicative demo prices** and are not treated as catalogue-confirmed prices.

## Publishing checklist

1. Confirm current selling price for each website product before launch.
2. Confirm which colour/variant names should be customer-facing.
3. Replace any demo price with the confirmed price, or switch the site to `Contact for price` if pricing changes frequently.
4. Confirm whether every catalogue group should be sold as one product family or split into separate colour/style products.
5. Keep `images/` beside `index.html` when uploading to GitHub so all relative image paths continue to work.
